# 🧮 Calculadora Profissional

Uma calculadora desktop completa com interface moderna, criada com Python, Flask e PyWebView.

## ✨ Funcionalidades

- ✅ Operações básicas (+, -, ×, ÷)
- ✅ Porcentagem (%)
- ✅ Memória (M+, M-, MR, MC)
- ✅ Histórico completo
- ✅ Atalhos de teclado
- ✅ Tema claro/escuro
- ✅ Interface estilo Windows
- ✅ Testes automatizados

## 🚀 Como executar

### Opção 1: Executável
Baixe o arquivo `Calculadora_Profissional.exe` e execute.

### Opção 2: Código fonte
```bash
git clone https://github.com/PaNiiCz/Calculadora.git
cd Calculadora
pip install -r requirements.txt
python desktop.py
